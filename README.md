# Mutagenicity_Intergrated-Model
This repository holds the data associated with the manuscript <b> Establishment of Integrated Model for Predicting Compound Mutagenicity with a Feature Importance Analysis.</b> Compound datasets used for model training and testing in this study are provided.

<b> Manuscript </b><br/>
Establishment of an Integrated Model for Predicting Compound Mutagenicity with a Feature Importance Analysis.
Chao-Hsu Yang, Tony Eight Lin, Jui-Hua Hsieh, Kai-Cheng Hsu, and Pei-Te Chiueh
Journal of Chemical Information and Modeling 2025 65 (21), 11558-11571
https://doi.org/10.1021/acs.jcim.5c01586
